# Online Könyvtár

Webprogramozás beadandó projekt.

## Projekt leírás

Az alkalmazás egy online könyvtár rendszer, amely lehetővé teszi:

- könyvek megjelenítését
- regisztrációt és bejelentkezést
- könyvek kölcsönzését
- könyvek visszahozását
- keresést
- admin jogosultságkezelést
- könyvek hozzáadását és törlését

## Használt technológiák

- Node.js
- Express.js
- SQLite
- HTML
- CSS
- JavaScript
- Git és GitHub
